# Security

Clippo sees everything you copy, so security reports are taken seriously.

If you find a way for Clippo to leak clipboard contents, store something it shouldn't (like a password from a password manager), or expose its data to other apps, please don't open a public issue. Report it privately here instead:

https://github.com/Lorder19/clippo/security/advisories/new

I'll reply as soon as I can and credit you in the release notes unless you'd rather stay anonymous.

Only the latest release gets fixes.
